# Play Pulse

Приватний сайт із новинами Google Play, Play Console та Android-гемблінгу, і Telegram-бот, який читає ту саму стрічку напряму з сайту.

- **Поточний сайт:** [Play Pulse](https://playpulsenews.play-pulse-cloudflare.workers.dev). Доступ має лише власник через логін і пароль Play Pulse; посилання не робить сайт публічним.
- **Моніторинг:** документація передбачає щоденне оновлення близько **10:00 за Києвом**. Telegram-бот може автоматично надсилати нові записи після появи у спільній стрічці; налаштування та захист від повторів описані в `bot/README.md`.
- **Telegram-бот:** [@PlayPulseNewsBot](https://t.me/PlayPulseNewsBot) приймає команди через Cloudflare webhook і надсилає нові записи дозволеному власнику. Стан доставки збережено в D1; Mac для роботи бота не потрібен. Інструкція: `bot/README.md`. Не надсилайте токени чи паролі в чат.
- **Cloudflare Free:** сайт, спільна стрічка та бот перенесені в Worker і D1. Нові публікації з попереднього приватного [сайту Sites](https://play-pulse-news.nemofresh.chatgpt.site) переносяться раз на хвилину. Цей міст доставляє готові новини; щоденну автоматизацію пошуку о 10:00 не знайдено й не підтверджено. Налаштування та порядок перевірки: [deploy/CLOUDFLARE.md](deploy/CLOUDFLARE.md).
- **Render:** підготовлені окремий приватний Node.js-сервер сайту, постійне сховище, міст живої стрічки та Background Worker бота. Порядок перенесення даних, ключів і стану доставки: [deploy/RENDER.md](deploy/RENDER.md). Конфігурація сервісів: `render.yaml`.

## Що в архіві

- `site/dist/`: вихідні файли дизайну та статична початкова стрічка `news.json`.
- `site/worker/`: спільна логіка серверних маршрутів, збірка й тести. `site/server/`: приватний сервер Node.js для Render. Приклад маніфесту в `site/.openai/hosting.example.json` не прив’язаний до чинного розгортання.
- `bot/`: код, тести, аватар, параметри запуску без секретів і Dockerfile.
- `cloudflare/`: приватний шлюз, D1, webhook, доставка сповіщень, окремий обробник автентифікації й інструмент імпорту.

**Статична стрічка в архіві не є повною копією поточної живої стрічки.** Записи, додані після запуску, зберігаються у приватному сховищі сайту. Архів не містить живу базу, паролі, токени, облікові записи чи сесії. Не розміщуйте цей Worker публічно без переналаштування перевірки доступу: він спирається на приватний шлюз ChatGPT Sites.

## Локальні перевірки

Node.js 22+:
- `npm --prefix site test` перевіряє Node.js-сервер, приватний доступ, сховище, міст стрічки та інтерфейс кабінету.
- `cd site && node worker/test-worker.mjs && node worker/test-account.mjs`
- `cd site && node worker/build-worker.mjs` створює серверний файл у `dist/server/` без розгортання.
- `cd bot && node --test` перевіряє бота без зовнішніх запитів.
- `npm --prefix cloudflare test` перевіряє перенесення, приватний доступ і хмарного бота; `npm --prefix cloudflare run build` виконує Wrangler dry-run без публікації.
