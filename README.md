# Play Pulse

Приватний сайт із новинами Google Play, Play Console та Android-гемблінгу. Telegram-бот читає ту саму стрічку й надсилає кожну новину окремим повідомленням із повним викладом та посиланнями на джерела.

## Поточний запуск

Сайт [Play Pulse](https://playpulsenews.play-pulse-cloudflare.workers.dev) і [@PlayPulseNewsBot](https://t.me/PlayPulseNewsBot) працюють на Cloudflare Free. Сайт відкривається після входу власника; посилання не надає доступу. Повна стрічка з 41 запису та стан доставки перенесені до D1. Бот приймає приватні команди через webhook, тому Mac для його роботи не потрібен. Локальний LaunchAgent зупинено й вимкнено.

Для пошуку та публікації новин діє одне прив’язане хмарне завдання Sites: щодня о 10:00 `Europe/Kyiv`. Перший плановий запуск 24.11.2026 додав одну перевірену новину про Google Play Store v54.2. Звіт завдання, живі стрічки та checkpoint каналу підтвердили результат: тепер 42 матеріали, 41 попередній запис збережено. Інструкція: [deploy/news-monitor-prompt.md](deploy/news-monitor-prompt.md), метадані: [deploy/news-monitor.json](deploy/news-monitor.json).

24.11.2026 до чинного завдання додано 16 джерел і тематичних стрічок: Google Ads, Firebase, безпека Android, ASO, профільні медіа, регулятори, YouTube та два Telegram-канали. Повний [каталог джерел](deploy/news-sources.md) визначає їхню роль: офіційні матеріали й власні дослідження можуть бути основними джерелами, медіа та пошукові сигнали потребують перевірки першоджерела. Інструкцію збережено в наявному хмарному завданні; розклад, адреса публікації та приватний доступ збережені.

Завдання публікує перевірені матеріали на попередньому приватному [сайті Sites](https://play-pulse-news.nemofresh.chatgpt.site). Щохвилинний міст переносить нові ID до спільної стрічки Cloudflare, зберігаючи правки власника. Окремий щохвилинний пошук новин не запускається. Транспорт публікації перевірено повторним записом наявної новини: `200`, `changed: false`, стрічку з 41 запису збережено.

Підтримку каналу й повних окремих повідомлень розгорнуто у версії `f77c6bc0`. Приватний канал Play Pulse створено в обліковому записі власника; через Telegram API перевірено його приватність, власника й право бота лише публікувати повідомлення. Хмарний Cron доставив усі 41 новину архіву від старих до нових, до трьох повідомлень за виклик, без особистих копій. Завершення підтверджено 24.11.2026: усі ID присутні в checkpoint без повторів, останні дописи перевірено в Telegram, повний текст 11 доступних карток звірено зі стрічкою. Налаштування та захист від повторів описано в [bot/README.md](bot/README.md).

Інструкція чинного розгортання: [deploy/CLOUDFLARE.md](deploy/CLOUDFLARE.md). Реалізація для Render залишається в репозиторії як підготовлений альтернативний варіант; сервіси Render не є поточним запуском. Її опис: [deploy/RENDER.md](deploy/RENDER.md).

24.11.2026 власник обрав лаконічний професійний стиль дописів. Усі 41 текст відредаговано зі збереженням фактів, дат і джерел, синхронізовано в обох живих стрічках і змінено в наявних повідомленнях каналу без повторної розсилки. Новий формат починається із заголовка, зберігає короткі абзаци й показує джерела компактними посиланнями. Редакційні правила збережено також у чинному хмарному завданні. У 8 дописах додано справжні обкладинки з повним українським підписом; автоматичне читання медіа джерел для каналу розгорнуто у версії `13c4cdf0`.

Кожна новина містить посилання «Новина на Play Pulse» на власну сторінку `/?article=<ID>#news`. Сайт відкриває відповідну картку з повної стрічки, а після входу повертає до неї. Адресу сайту також додано до повного й короткого описів бота. Ці зміни розгорнуто у версії `87dcb1aa`; у всіх 42 наявних дописах посилання додано редагуванням на місці зі збереженням 8 фото й повного тексту.

Попереднє завдання «Новини Google Play і Play Console» продовжує особисте зведення в ChatGPT; запис на сайт у ньому явно вимкнено. Публікацію на сайт виконує тільки прив’язане завдання Play Pulse. Розклад 10:00 за Києвом збережено.

## Файли проєкту

- `site/dist/`: дизайн та статична початкова стрічка з 12 записів.
- `site/worker/`: спільна серверна логіка, збірка й перевірки. `site/server/`: окремий приватний сервер Node.js для альтернативного запуску.
- `bot/`: бот, форматування повідомлень, тести, аватар та інструменти локального запуску.
- `cloudflare/`: приватний шлюз, D1, webhook, доставка, Durable Objects та інструмент імпорту.
- `deploy/`: інструкції розгортання й відкриті параметри хмарного моніторингу без секретів.

Статичний `site/dist/news.json` не є повною копією живої стрічки. Живі новини, кабінет і сеанси зберігаються у приватному сховищі. Секрети та приватні експорти до Git не додаються. Вихідний Worker у `site/worker/` залежить від довіреної перевірки доступу; публічний запуск має використовувати приватний шлюз із поточної конфігурації Cloudflare.

Оригінальні `Play-Pulse-Overview.md`, `Play-Pulse-Start-Here.md`, `Play-Pulse-Project-Instructions.txt` і `Play-Pulse-Project.zip` збережені без змін. Вони описують початковий стан; актуальний запуск наведено вище.

## Локальні перевірки

Потрібен Node.js 22+. Із кореня проєкту:

```sh
npm --prefix site test
npm --prefix bot test
npm --prefix cloudflare test
npm --prefix cloudflare run build
```

Окрема збірка вихідного Worker: `cd site && node worker/build-worker.mjs`. Вона створює `site/dist/server/` без публікації. Wrangler dry-run також нічого не розгортає.
